# Квесты

Структура как в `docs/art`: `<глава>/<биом>/<тип>/`. Главы C1-Yav, C2-Nav, C3-Prav; биомы по кольцу GDD §3.

Каркас системы — `docs/systems/secrets_v0.1.md` (движок «Обряд»). Лор цепочек Высей — `docs/lore/vysi_secrets_v0.1.md`.

| Папка типа | Что внутри |
|---|---|
| `story/` | сюжет главы: наставник, экзамен, закрепление |
| `tutorial/` | обучающие квесты, которые показывают механику |
| `side/` | побочные квесты от NPC |
| `hidden/` | скрытые цепочки без квеста (движок «Обряд») |
| `passages/` | скрытые проходы: видимые (трещины) и невидимые (удар / действие / квест) |
| `dungeons/` | подземелья: в конце всегда босс или элита с дропом |
| `super/` | супер-квесты, которые идут через несколько биомов и миров |

Карточка квеста: зона и координаты, шаги (глагол, объект, предмет, условие), намёки в мире, реплики, награда, кто из стадий может, статус (идея / черновик / в игре).
