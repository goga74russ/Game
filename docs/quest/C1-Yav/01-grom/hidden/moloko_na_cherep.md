# «Молоко на череп» — скрытая цепочка

**Статус:** в игре, простая версия (грейбокс), 2026-09-27. Идея директора; лор — `docs/lore/vysi_secrets_v0.1.md` (С1).

| Шаг | Где | Что | Кто может |
|---|---|---|---|
| 1 | Ведёрный ряд, загон (524, −38) | Коза — подоить → крынка молока в Суму | только Плоть (у Скелета протекает) |
| 2 | Ворота загона (539, −28) | Конский череп на колу — полить молоком | с молоком (то есть Плоть) |
| Итог | | Череп снимается с кола → облик-шлем «Конский оголовок» | |

**Намёк/отклик:** выстрел в череп — звякает медный бубенец.
**Полная версия (позже):** громовое молоко от козы с опалённым боком; полить, пока звенит бубенец от удара дуба; эффект шлема — бубенец звякает перед ударом жилы рядом.
