## Реализованный доступ к сумке

У Искры инвентаря нет. Скелет получает его после принятия пояса с калитой у деда после Присяжного камня. У Плоти сумка остаётся; камни переставляются у требы.

## Что ещё доводим

Финальный облик героя и наставника, анимации и читаемость экзамена, элиты, поддержки, свет и звук, сохранение прогресса и прохождение внешним тестером. Подробный порядок разработки остаётся в плане демо.
