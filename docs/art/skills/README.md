# Навыки: облик

Руны, иконки и эффекты навыков. Механика и цифры — `docs/systems/skills/` (таблицы).

**Руна = цвет (стихия) + узор (глагол) + рамка (метка)** — одна и та же руна служит иконкой на панели и подсказкой на рунной двери (`docs/systems/skills_demo_v0.1.md` §3).

| Рамка | Метка |
|---|---|
| квадрат | удар (сила от ближнего оружия) |
| ромб | выстрел (от дальнего) |
| круг | чары (от оружия не зависит) |

| Стихия (бог) | Цвет | Знак по краю (для дальтоников) |
|---|---|---|
| Гром (Перун) | холодный голубой-фиолетовый | зигзаг |
| Ветер (Стрибог) | бледная бирюза | завиток |
| Солнце (Дажьбог) | золото | лучи |
| Жар (Сварог) | медь-оранжевый | зубцы-язычки |
| Ртуть (Велес) | серебро-сталь | капли |
| Нити (Мокошь) | зелень льна | переплёт |
| Порча (Чернобог) | болотный чёрно-зелёный | пятна |
| Ярь-кровь (Ярило) | тёмная вишня (не чистый красный) | колосья |

| Глагол | Узор | Глагол | Узор |
|---|---|---|---|
| площадь | круг с точкой | щит | полукруг-чаша |
| обездвиживание | крест в круге | призыв | фигурка-столбик |
| цепь | три точки на линии | рывок | стрела с хвостом |
| снаряд | точка + черта | лечение | росток |
| дебафф | перечёркнутый ромб | аура | круг из черточек |

Каналы цвета (GDD §9, §12) действуют и здесь: красно-белое — только атаки наставника, восковое золото — лут, лунное серебро — треба.

Структура: `<глава>/<биом>/` — карточка на камень (иконка-руна, эффект, звук, что видно с камеры).
