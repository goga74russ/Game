## Общая сетка руны (v0.1, [предл.] art-director)

Одна геометрия для всех рун, чтобы генератор и художник рисовали одинаково. Цифры — в пикселях холста 256×256 (масштабируются пропорционально).

| Элемент | Геометрия | Толщина |
|---|---|---|
| Холст | 256×256, центр (128,128) | — |
| Рамка «квадрат» (удар) | квадрат 196×196, углы срезаны фаской 14 px (как у тёсаного камня) | 14 px |
| Рамка «ромб» (выстрел) | квадрат 166×166, повёрнут на 45° (вершины на 11 и 245 px по осям) | 14 px |
| Рамка «круг» (чары) | окружность Ø 204 | 14 px |
| Знак Грома по краю — зигзаг | ломаная вдоль всего внешнего контура рамки, отступ 6 px наружу, амплитуда 8 px, шаг 18 px, острые углы | 5 px |
| Узор (глагол) | внутри рамки, вписан в круг Ø 120 | 12 px |
| Точки узора | сплошные круги Ø 26 | — |
| Концы линий | обрублены прямо, как резцом; без скруглений | — |

**Цвет (Гром).** Линии #8FA8FF; по оси каждой линии тонкая жилка ядра #DDE4FF шириной 3 px (не чистый белый). Фон плитки панели — тёмный сланец #1E2230, по краю плитки фаска #2B3040 2 px. Вне рамки — мягкий ореол #8FA8FF 35%, радиус 6 px.

**Состояния на панели.**
| Состояние | Вид |
|---|---|
| Доступна | как выше, 100% |
| Мало Яри | линии в серый #6B7080 с сохранённой жилкой #8FA8FF 50%; ореола нет; цифра цены (рисует HUD) — тускло-костяная |
| Перезарядка | поверх руны сектор-затенение #0C0E14 70%, сходит по часовой стрелке от 12 часов; рамка остаётся цветной, узор под тенью; в момент готовности одна вспышка ядра на 0,15 с (не пульс: пульс — канал требы) |
| Нет камня | пустое гнездо: только контур рамки #3A3F4E 4 px, без узора и зигзага |

**На раме рунной двери (резьба по камню).** Руна ~18 см в поперечнике [предл.], вырезана в сером камне рамы бороздой глубиной ~6 мм с V-профилем. Борозды заполнены тусклой лавандовой минеральной смолой или фульгуритовым стеклом #6F7FB8 (матовое, без эмиссии: окружение ≤60%). Зигзаг по краю — мелкая насечка. Когда у героя на панели есть подходящий камень, борозды руны светятся изнутри #8FA8FF, ровно, без пульса [предл.]. Пустое гнездо ульты — гладкий круг без резьбы.
