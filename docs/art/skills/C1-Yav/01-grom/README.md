# Навыки · Явь · Гром — Перун

Цвет всех рун — холодный голубой-фиолетовый, знак по краю — зигзаг. Эффекты в прототипе — отладочные линии; облик ниже — задача арт-директору.

| Камень | Рамка | Узор | Руна | Эффект (что нарисовать) | Статус облика |
|---|---|---|---|---|---|
| Громовой удар | квадрат | круг с точкой | удар / площадь | дуга разряда перед героем (у Искры — кольцо) | пробел |
| Громоотвод | круг | крест в круге | чары / обездвиживание | стержень в земле, круг-телеграф, удар молнии сверху | пробел |
| Сполох | круг | стрела с хвостом | чары / рывок | вспышка-след рывка | пробел |
| Цепная искра | ромб | три точки на линии | выстрел / цепь | молния, прыгающая между целями | пробел |
| Оберег грозы | круг | полукруг-чаша | чары / щит | купол-оберег, при пробитии — разряд кругом | пробел |

Малая рунная дверь демо: Громовой удар + Громоотвод + Цепная искра.
