# Герой: Искра, Скелет, Плоть

> Часть библии персонажей главы Перуна (v0.1, черновик art-director). Общие правила, перепись, бюджеты и вопросы — `docs/art/C1-Yav/01-grom/README.md`. Пометки: **[предл.]** — предложение, **[пробел]** — нет в документах, **[Д]** — ориентир.

### S1. Герой: общие правила трёх стадий

- **Пол:** в демо Плоть только мужская, женская база — позже (решение директора 2026-09-27). В тексте (T) пол не называется: героя зовут по стадии — огонёк, кости, пришлый, ученик.
- **Камера за плечом** (GDD §5): героя почти всё время видно **со спины и в три четверти сзади**, на 3–5 м. Узнаваемость стадии должна держаться на **спине, плечах и затылке**, а не на лице [предл.].
- **Цвет свечения** — стихия стартового бога. В демо это Перун: холодная лаванда #8FA8FF, ядро #DDE4FF, без чистого белого (GDD §4, style §4; параметр `SparkColor`, C). Свечение канала 5: насыщенность ≤80%.
- **Яркость по стадиям:** Искра — яркая плазма; Скелет — тусклое тление; Плоть — без свечения (GDD §4).
- **Единые пропорции Скелета и Плоти** [предл.]: T §3 говорит, что «тело будто знает, как это делается». Кости Скелета — это кости будущей Плоти.
- **Что уже есть (C, «Ассеты: модель Скелета»):** Скелет в игре — Fab «Free Pack - Human Skeleton» + авториг Mixamo, ретаргет со скрытого Wraith. Для Плоти рекомендован MetaHuman на риге Epic (решение за директором). Значит, риги разные: пропорции Скелета нужно подогнать под будущую Плоть, иначе превращение «скачет» по росту [предл.].
- **Рост Скелета и Плоти** — [пробел]. [предл.] 1,78 м ±5 см, обычные человеческие пропорции, без героической гипертрофии.

### S1.1. Искра

| Поле | Описание |
|---|---|
| Суть | Душа-огонёк: «небольшой, с ноготь». Висит над землёй, двигается телепортом, как пламя свечи, которое ловит сквозняк (T §1). Стреляет плазмой, ближний бой — вспышка вокруг себя R 2,6 м (C) |
| Силуэт, 3 ракурса | Шарообразный, ракурсы одинаковы. Спереди, сбоку и сзади — ядро и мягкий язык пламени, который отклоняется против движения [предл.] |
| Размер | Ядро «с ноготь» (T). Размер под читаемость, крупнее «ногтя», принят (решение директора 2026-09-27): ядро 3–4 см, плазменная оболочка Ø 0,35–0,5 м, высота парения 1,1–1,3 м (центр кадра для камеры) |
| Материалы | Нет меша. Весь персонаж — VFX (Niagara): ядро, оболочка, короткий шлейф |
| Палитра | Ядро #DDE4FF, оболочка #8FA8FF, край оболочки прозрачный |
| Свечение | Всё тело. Яркость наибольшая из трёх стадий, но ниже канала 1 во время телеграфа (style §2) |
| Износ / «померкшесть» | Нет: это не навья |
| Лицо | Нет |
| Камера 5–20 м | Лавандовая точка с шлейфом. На фоне неба #A9C4D6 рискует потеряться. [предл.] Держать тёмную окантовку-виньетку внутри оболочки или поднять яркость ядра |
| Анимация | Висение с мелким дрожанием, телепорт (исчезнуть и появиться с коротким следом), отклонение пламени при стрельбе. «Кивок» — вздрагивание вниз [предл.] |
| Телеграф | Не нужен (игрок) |
| Звук | [предл.] Тихий шелест пламени, при телепорте — сухой хлопок, при выстреле — короткий треск |
| Смена стадии | После 5 убийств огонёк «тяжелеет» и опускается в затишке. Кости собираются вокруг него, как иней на травинке: позвонок, рёбра, череп (T §3). Смена стадии — полное лечение и 1,5 с неуязвимости (C) |

### S1.2. Скелет

| Поле | Описание |
|---|---|
| Суть | Человеческий скелет. Огонёк горит в черепе, «как в фонаре» (T §3). Говорить не может, отвечает кивком. Уклонение — рывок, «коротко, со стуком». Ближний бой — удар рукой (GDD §5, C). Держит оружие 1 (самопал) после Присяжного камня (L, T §4) |
| Силуэт | **Спереди:** узкий, светится только глазница или череп целиком. **Сбоку:** позвоночник читается S-образно, рёбра — клетка. **Сзади (главный ракурс):** позвоночник и затылок черепа с просвечивающим огоньком [предл.] |
| Пропорции | Те же, что у Плоти (S1). Кости чуть крупнее анатомических, чтобы силуэт держался на 5–20 м [предл.] |
| Материалы | Кость: сухая, матовая, не полированная. Швы черепа и суставы чуть темнее [предл.] |
| Палитра | [предл.] Кость #CFC4A8 (светлая кость, style §3), суставы и швы #8E826A |
| Свечение | «Тусклое тление в костях» (GDD §4). [предл.] Лаванда #8FA8FF едва тлеет в суставах, ярче всего в черепе (огонёк) и в центре грудной клетки. Интенсивность ~30% от Искры |
| Износ | Нет гнили и сколов: кости новые, только что собранные. Не использовать «могильную» грязь (скелет — облачение души, а не мертвец, F §5) |
| Лицо, мимика | Череп без челюстной мимики. Эмоцию передаёт огонёк: вспыхивает, тускнеет, «кивает» вместе с головой [предл.] |
| Камера 5–20 м | Светлая кость на тёмной траве — самое светлое пятно на среднем плане. Риск: герой ярче врагов в сером тесте, это правильно. Огонёк в черепе виден со спины сквозь глазницы и затылочное отверстие [предл.] |
| Анимация | Шаг лёгкий, с сухим перестуком. Рывок — резкий сдвиг корпуса и стук. Удар рукой — короткий тычок. Кивок — кивок всем черепом |
| Звук | Рывок — «со стуком» (T). [предл.] Шаги — сухой деревянный перестук, тише шагов наставника |
| Смена стадии | Под навесом Стрелокопен на кости нарастает мясо, «быстро и некрасиво: сначала жилы, потом кожа, как тесто на кости». Огонёк уходит внутрь, под рёбра (T §5). [предл.] Переход — 2–3 с, самый заметный VFX главы; держать без крови ярче #8A1020 |

### S1.3. Плоть

| Поле | Описание |
|---|---|
| Суть | «Голый человек обрастает снаряжением»; к экзамену приходит почти голым, с оружием (GDD §4). Перекат с i-frames, ближний бой оружием (GDD §5) |
| Состояния облика | (1) **Голый** — сразу после превращения, под навесом (T §5). (2) **+ рубаха стрелокопа** — «жёсткая, пахнущая чужим потом и горячим камнем» (T §6). (3) **+ грубые кожаные наручи** (T §6). В игре это 2 предмета брони из сарая (L §2.4, C) |
| Пол, лицо, волосы, телосложение | **Мужчина** (в демо — единственная база; женская позже) (решение директора 2026-09-27). Лицо, волосы — [пробел]. [предл.] Обычное худощавое телосложение, 1,78 м |
| «Голый» | Тело голое (решение директора 2026-09-27). **На подумать (рейтинг):** повязка из небелёного льна, «наросшая» вместе с кожей. Пока не моделируется |
| Силуэт | **Сзади (главный):** голая спина → светлый прямоугольник рубахи → наручи дают тёмные «манжеты» на руках. Каждая стадия снаряжения должна читаться со спины. **Сбоку:** оружие за спиной или в руках (отдельные ассеты). **Спереди:** лицо — только в катсценах и диалоге |
| Материалы | Кожа новая, матовая, чуть бледнее нормы в первые минуты [предл.]. Рубаха — грубый небелёный лён, серый от песка и пыли. Наручи — сыромятная кожа, шнуровка, без металла [предл.] |
| Палитра | [предл.] Кожа — натуральная, без розовой насыщенности; рубаха #8C8474 → пыль #A8996A по подолу; наручи #4A3A2A, шнур #6B5A44 |
| Свечение | Нет (GDD §4). Огонёк внутри, под рёбрами (T §5), не виден |
| Износ | Кожа чистая, новая: это облачение, а не рана. Рубаха — чужая, выношенная, с выгоревшими плечами [предл.] |
| Лицо и мимика | Мужское; конкретное лицо — [пробел]. [предл.] Спокойное, не героическое лицо без шрамов: за ним «своя, пусть и забытая, история» (F §5). Мимика нужна только в диалогах экзамена и эпилога: вдох, сжатые губы, вздрагивание |
| Камера 5–20 м | Со спины: цвет кожи и рубахи на тёмной траве, оружие. После победы на экзамене — **серебряный след на плече** (T §7, V §6), см. ниже |
| Анимация | Перекат, ближний удар колуном (решение директора 2026-09-27), стрельба от бедра и в прицел. **В эпилоге герой вздрагивает от грома** — рывок камеры и тела (C, решение директора 2026-09-26) |
| Звук | [предл.] Босые шаги по сухой траве → с рубахой добавляется шорох ткани, с наручами — скрип кожи |
| След победы (исход Б) | Одна серебряная пылинка садится на плечо и остаётся «тусклым серебряным следом» (T §7). Косметика без силы (GDD §9), вид открыт (T, V). **Риск канала 4:** серебро + ореол = треба. [предл.] Матовое пятно-вкрапление в коже или ткани плеча, без ореола и пульса. Плечо — со стороны камеры (правое при камере за правым плечом), чтобы след был виден (требование T, V) |

**Оружие** — отдельные ассеты, в этом документе не прорабатываются: самопал (короткий ствол, ложе из тёмного дерева, в замке громовая стрела «с ноготь», вспыхивает голубым; T §4); пищаль с раструбом, набитая сечкой из битых стрел (T §6); ближнее оружие Плоти — **колун для дров** (решение директора 2026-09-27): [предл.] топорище из тёмного дерева ~0,7–0,8 м, клиновидный тяжёлый обух, железо с окалиной, без узоров; дальнее оружие Плоти — «минимальное, решается позже» (решение директора 2026-09-27), помимо пищали — [пробел].
