# Руна-ключ на земле

> Общие правила и негатив — `README.md`. В документах руна-ключ упомянута только в правилах смерти: «руны-ключи и камни-навыки не выпадают (прогресс, а не добыча)» (consensus, 2026-09-27). **Что открывает ключ и как связан с рунной дверью — [пробел].** Облик ниже — [предл.] целиком, чтобы его не спутали с камнем-навыком.

- **Предложение [предл.]:** руна-ключ — **резная дощечка-плашка из чёрного дуба** (то же дерево, что наличники и рама рунной двери). Камень-навык = камень, ключ = дерево. Это разводит их по материалу, форме и звуку.
- **Силуэт (0,5 с):** **длинный узкий брусок** 16×4×2 см с одним скошенным «зубом» на конце — как бородка ключа, только деревянная. Камень — овал, ключ — палочка.
- **Слои материалов:**
  1. Тело — морёный дуб #2A241E, по волокну продольные трещинки.
  2. Резьба — на лицевой стороне одна руна-узор без рамки (рамку даёт дверь), глубина 2 мм, на дне резьбы — остатки старой охры #9C7A3A.
  3. Зуб — стёсан под углом 30°, на торце выжжен шестилучевой громовой знак Ø 1,5 см.
  4. Шнурок — льняной #8C8474 через отверстие Ø 5 мм на другом конце.
- **Свечение:** нет. Ключ «спит», пока не поднесён к двери [предл.]: у двери резьба загорается цветом гнезда.
- **Износ:** углы стёрты пальцами, шнурок обтрёпан.
- **Палитра:** #2A241E, #9C7A3A, #8C8474.
- **На земле:** плашмя; столб #FFC24A; **кольцо охры #9C7A3A** (квестовое).
- **С камеры за плечом:** тёмная палочка в золотом столбе; отличие от камня — вытянутость.
- **Звук [предл.]:** подбор — сухой деревянный стук, без разряда.
