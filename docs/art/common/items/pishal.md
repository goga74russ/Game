# Дробовик — пищаль с раструбом

> Общие правила и негатив — `README.md`. Источник: hero_v0.1 — «пищаль с раструбом, набитая сечкой из битых стрел (T §6)»; GDD §4, skills_demo §1 (дробовик: Цепная искра — 2 цели в упор).

- **Что это:** короткая тяжёлая пищаль копателей, стреляет сечкой из битых громовых стрел.
- **Силуэт (0,5 с):** **раструб-воронка на конце ствола** — главный и единственно нужный признак; развести с самопалом с первого взгляда. Ствол длиннее, ремней нет — ствол сидит на двух железных кольцах.
- **Размеры [предл.]:** общая длина 96 см; ствол 55 см; раструб — длина 12 см, Ø устья 9 см (ствол 4 см); приклад изогнут вниз «лопаткой» 14 см высотой; на вид ~4,5 кг.
- **Слои материалов:**
  1. Ствол — железо #2E2C2C с окалиной #4A3E36; раструб выкован отдельно, края развальцованы и обкусаны, внутри — зеленоватый налёт стеклянной пыли #8C9A8E от сечки.
  2. Кольца — два железных обруча 2 см шириной, один лопнул и схвачен проволокой.
  3. Ложе — берёза, потемневшая до #6E5E48, приклад-«лопатка» с трещиной, стянутой медной скобой #6FA890 (медь-патина Высей).
  4. Замок — простой фитильный рычаг-«серпентин»; тлеющий фитиль даёт крохотную тёплую точку #B8652A [предл.] (не золото — не путать с лутом).
  5. Мешочек с сечкой на ремне, льняной #8C8474, из горловины торчат осколки стекла.
- **Износ:** копоть по всему раструбу изнутри #1E1B1A, зазубрины от стеклянной сечки на кромке, приклад отшлифован плечом.
- **Палитра:** #2E2C2C, #4A3E36, #1E1B1A, #8C9A8E, #6E5E48, #6FA890, #8C8474, фитиль #B8652A.
- **На земле:** на боку раструбом к камере; столб #FFC24A из середины; без кольца.
- **В руке:** держат двумя руками у бедра; раструб выступает за силуэт героя.
- **С камеры за плечом:** тёмная труба с расширением — даже в силуэте ясно «бьёт веером». Выстрел — веер осколков, стеклянные искры #8C9A8E + лавандовые отблески #8FA8FF по краям.
- **Звук [предл.]:** глухой рык + звон стеклянной сечки по камню; перезарядка — сыплющийся звон осколков в дуло.
