# Стрела с неба (оплавленная)

> Общие правила и негатив — `README.md`. «Что с неба»: в Стрелокопнях среди простых громовых стрел лежит одна «с оплавленным концом» → в Суму → положить под чёрную матицу избы на ударе дуба (`docs/quest/C1-Yav/01-grom/tutorial/chto_s_neba.md`). Дед: «Её в руке держат, пока не согреется».

- **Что это:** одна из «громовых стрел» Стрелокопен (фульгурит, props.md), но особая. Главная задача облика — **чтобы её нашли среди десятков простых** без подсказки текстом.
- **Силуэт (0,5 с):** простые стрелы — ветвистые серо-зелёные трубки. Эта — **прямая, без веток**, 28 см, и **один конец оплавлен в тёмную каплю-«наплыв»** Ø 3,5 см. «Палочка с набалдашником» против «коряжки».
- **Размеры [предл.]:** длина 28 см, Ø ствола 1,8 см, капля-наплыв Ø 3,5 см.
- **Слои материалов:**
  1. Ствол — стекло-фульгурит #8C9A8E, снаружи шершавое, с прикипевшим песком #A8996A.
  2. Внутри — полый канал, видно на изломе второго конца, стенки глянцевые (единственный блеск — внутри, не снаружи).
  3. Наплыв — оплавленное тёмное стекло #2E3034, гладкое, с радужной побежалостью [предл.] в фиолетово-сизую #5C6FB8 — **единственный цветной акцент**; без свечения.
  4. [предл.] По стволу — тонкая спиральная полоса более тёмного стекла, как след закрутки молнии.
- **Износ:** вторая сторона обломана неровно; песок в порах.
- **Палитра:** #8C9A8E, #A8996A, #2E3034, #5C6FB8.
- **На земле:** лежит в яме среди простых стрел, наплывом вверх — наплыв видно из ямы. Столб #FFC24A; кольцо охры #9C7A3A.
- **Под матицей:** стрела ложится на брус; в момент «своего часа» наплыв на мгновение теплеет до #8FA8FF (1 кадр) — единственная реакция, затем открывается подпол.
- **В руке:** Скелет/Плоть держат как свечу, наплывом вверх.
- **С камеры за плечом:** тонкая светлая палочка с тёмным набалдашником.
- **Звук [предл.]:** стеклянный звон-хруст при подборе, тише обычных стрел.
