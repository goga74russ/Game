# Крынка молока

> Общие правила и негатив — `README.md`. «Молоко на череп»: Плоть доит козу у загона (z4) → крынка молока в Суму → полить конский череп (`docs/quest/C1-Yav/01-grom/hidden/moloko_na_cherep.md`). Несёт только Плоть — у Скелета протекает (решение 2026-09-27).

- **Что это:** глиняный кувшин для молока с высоким горлом, обычный для деревни.
- **Силуэт (0,5 с):** **пузатое тулово + высокое узкое горло без ручки** (классическая крынка) — «груша вверх горлом». Без ручки — отличие от кувшина.
- **Размеры [предл.]:** высота 22 см, тулово Ø 15 см, горло Ø 8 см, венчик Ø 9 см; объём ~1,5 л.
- **Слои материалов:**
  1. Тело — обожжённая глина #8A6A50, чернёная (молочение/морение) до #3E342C пятнами — тёмная, дымчатая.
  2. Декор — по плечику прочерчена волнистая линия и ряд точек-ногтевых вдавлений; без росписи.
  3. Горло — повязано льняной тряпицей #B0A690 с бечёвкой #6B5A44 (крышка).
  4. Молоко — видно только если открыта: матовое сливочное #E6DDC6 (не #FFFFFF). Капля засохшего молока на плечике.
- **Износ:** скол на венчике, вытертое дно, тонкая трещина-волосок, пятна копоти.
- **Палитра:** #8A6A50, #3E342C, #B0A690, #6B5A44, #E6DDC6.
- **На земле / у козы:** стоит на земле у ног козы (появляется после дойки), столб #FFC24A, кольцо охры #9C7A3A (квестовое).
- **В руке:** Плоть несёт в левой руке за горло или прижав к боку; при поливе — наклон, струя сливочного цвета, без брызг-блеска.
- **Скелет пытается взять [предл.]:** молоко течёт сквозь рёбра — матовая струйка, крынка остаётся на земле. Подсказка «только Плоть» без текста.
- **С камеры за плечом:** тёмная груша в руке; светлая тряпица на горле — видна.
- **Звук [предл.]:** глухой стук глины, плеск внутри на бегу.
