## 0. Общие правила для всех предметов

1. **Лут на земле = канал 3.** Восковое золото #FFC24A — только у лута. Любой предмет на земле подаётся одинаково: **вертикальный столб** #FFC24A высотой 2,2 м [предл.], Ø 12–18 см, тёплое ядро, края гаснут в прозрачность; предмет медленно покачивается (±3 см, период 2 с) [предл.]. Редкость — **только кольцо у основания** Ø 40–60 см (style §2). Сам предмет в золото не светится: он матовый, такой же, как в руке.
2. **Кольцо редкости [предл.]:** обычный — без кольца; квестовый — тёмная охра #9C7A3A; навык/руна — цвет стихии (гром #8FA8FF, приглушён до 60%); реликвия (ульта) — двойное кольцо #FFC24A снаружи + #8FA8FF внутри.
3. **Звук подбора [предл.]:** короткий глухой звон, как ложка о глиняный горшок; у навыков и рун поверх — сухой треск разряда.
4. **Материалы Яви, сухо.** Тёмное дерево, железо с окалиной, кость, небелёный лён, глина, камень. Без мокрого блеска, хрома, пластика. Узоры — шестилучевой громовой знак, ромбы-обереги, северная резьба. Без хохломы и красно-белой вышивки.
5. **Эффекты игрока** — насыщенность ≤80%; молния Перуна — лаванда #8FA8FF, ядро #DDE4FF (не #FFFFFF).
6. **Камера за плечом** — за правым плечом, 2,5–3,5 м [Д]; предмет в руке — в нижней правой трети кадра. Всё, что не читается за 0,5 с на этой дистанции, — вторичная деталь.
7. **Масштаб:** рост героя 1,78 м [предл., hero_v0.1]. Размеры в карточках — в см.

## Общие условия промптов

**Картинка (GPT Image и т. п.), предметный концепт.** В каждый промпт уже вшит хвост: `Isolated object, centered, neutral mid-grey seamless background, soft even studio light from upper left, no cast shadow on background, painterly photorealism, dark folk-fantasy, 3/4 view.` Для сравнения генераторов менять только хвост, тело промпта не трогать.

**Meshy (3D):** одиночный объект, `PBR textures, no baked lighting, no shadows on texture, clean topology, real-world scale`.
