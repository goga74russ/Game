**Сквозные правила.**
1. Красно-белое (#E0102A + #FFFFFF) — только Суд наставника. Восковое золото #FFC24A — только лут/патроны/руны-предметы. Лунное серебро #CFE3F2 с ровным ореолом — только треба. Гнилушный #7FE8C0 — только уязвимые точки врагов.
2. Эффекты игрока — насыщенность ≤80%, мягкие края, короткая жизнь; без столба и обводки силуэта.
3. Мерцание = гроза и игрок; ровный пульс = треба; вертикальный столб + покачивание = лут.
4. Возле наставника гром немой: молнии на арене и в эпилоге без раската (только звук).
