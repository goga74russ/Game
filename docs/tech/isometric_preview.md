# Изометрический прототип — 2026-09-28

По просьбе директора текущий 3D-прототип переведён на фиксированную изометрическую камеру. Правила — GDD §5. Эволюция, камни, оружие, NPC и экзамен сохраняют существующие механики.

## Запуск

`game/FadedNav/Play.bat` собирает проект и открывает главу в отдельном игровом окне. `OpenEditor.bat` открывает проект в UE 5.8; режим Play использует ту же камеру.

## Управление

| Действие | Ввод |
|---|---|
| Движение относительно экрана | WASD |
| Направление героя и атак | Курсор |
| Стрельба; удар без дальнего оружия | ЛКМ |
| Ближний бой | ПКМ |
| Уклонение | Пробел; с движением — по движению, без движения — к курсору |
| Перезарядка | R |
| Смена найденного оружия | Q |
| Масштаб камеры | Колесо |
| Навыки | 1–3 |
| Взаимодействие | E |
| Древо | Tab; внутри дерева колесо меняет его масштаб |

Зоны навыков ставятся на землю под курсором с ограничением дальности. Пули и первый удар Цепной искры идут от оружия: высокая камера не позволяет стрелять через стены. Во время дерева боевые команды отключены; после закрытия управление курсором восстанавливается.

## Параметры для плейтеста

У `FNCharacter` в Camera/Isometric: Pitch −55°, Yaw −45°, Distance 2100 см, FOV 50°, допустимая дистанция 1300–3000 см, шаг колеса 180 см. Это стартовые настройки, не итог баланса. Камера перспективная, с постоянным ракурсом; вращение персонажа её не поворачивает.

## Проверка

Встроенный прогон `-IsometricTest` проверяет реальную проекцию курсора, попадание, блокировку стеной, Цепную искру и расход патрона, движение, уклонение, пределы масштаба, открытие/закрытие дерева и стадии героя. Для независимого прогона используется пустая карта движка с тестовой ареной:

```powershell
& 'D:\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe' '<папка проекта>\FadedNav.uproject' '/Engine/Maps/Entry?Arena' -game -IsometricTest -RenderOffscreen -windowed -resx=1600 -resy=900 -unattended -nosound
```

Лог содержит `[IsoTest] PASS/FAIL` и итог `failures=...`; снимки сохраняются в `Saved/Screenshots/Isometric`. Проверку художественной читаемости, удобства наведения на слабые точки и ракурса всех участков Высей завершает плейтест.
