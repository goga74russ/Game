# Инвентарь демо: подготовка без пересечения с Aura

2026-09-28. Директор разрешил готовить экран и логику отдельно, пока Aura меняет визуал Искры.

## Что готово

`FNInventory.h/.cpp`: снимок текущего снаряжения, найденных камней, трёх ячеек панели и шести ячеек калиты. Предметы остаются в AFNCharacter: экран не дублирует владение, не расходует и не выбрасывает вещи. Снаряжение пока отображается, переодевание и смена оружия мышью не добавлены: в текущем коде доспех — суммарный бонус, а оружие переключается Q.

Canvas-экран использует существующие шрифты HUD. Камень выбирается мышью, затем нажимается ячейка 1–3. Перенос установленного камня меняет две ячейки местами. В пути доступен только просмотр. Без текстуры показано название; без владения — «Не найден». Поддержки обозначены как следующий шаг, их механика не имитируется.

Иконки передаются через таблицу `TMap<int32, UTexture2D*>`: 0 — Громовой удар, 1 — Громоотвод, 2 — Сполох, 3 — Цепная искра, 4 — Оберег грозы. Существующие PNG нужно импортировать как UI-текстуры после завершения работы Aura; пока ресурсы в редакторе не изменяются. HUD хранит текстуры и шрифты через UPROPERTY, иначе сборщик мусора может освободить их.

## Подключить после работы Aura

1. В AFNCharacter добавить открытие на I и закрытие на I/Esc, состояние инвентаря, запрет боевых действий и движения, остановку запросов стрельбы. Не разрешать открытие во время смерти/уклонения. Дерево/карта/инвентарь взаимоисключающие. Курсор показывать, смену режима ввода и замедление мира восстанавливать при закрытии и смерти; использовать те же правила, что у текущих меню.
2. Добавить API проверки нахождения у требы. Это текущая дистанция до действующей AFNTreba, а не «когда-то отдохнул» и не расстояние до стартового чекпоинта. Порог нужно согласовать с радиусом взаимодействия требы.
3. Добавить API применения целой панели: заново снять состояние и выполнить PlanAssignment/проверку владения, отсутствия дублей, стадии и доступа к требе. Не доверять старому снимку интерфейса. Перестановка не сбрасывает откаты: существующий код хранит их по ячейкам, при перестановке переносить таймер вместе с камнем. Не разрешать обход восстановления заменой камня на тот же.
4. В AFNHUD хранить FFNInventoryScreen, шрифты и текстуры. Пока меню открыто: Capture(hero, canEdit), Draw(Canvas, snapshot, fonts, icons). ЛКМ передавать в Click только на фронте нажатия, не каждый кадр. Callback вызывает API персонажа, а не пишет в снимок. Reset при новом открытии.
5. Собрать основной проект после закрытия редактора. Проверить реальные предметы, импортированные иконки, кириллицу, размеры 1280×720/1920×1080, блокировку боя, Esc, переход стадий, смерть и перестановку навыков с откатом.

## Граница готовности

В этой подготовке не изменяются FNCharacter, FNHUD, FadedNav.Build.cs, материалы, Niagara и настройки основного проекта. Поэтому I пока не открывает экран. Подключение и проверка в игре — отдельный следующий шаг после окончания правок Aura.

Автотест `FadedNav.Inventory.Assignment` проверяет запрет смены в пути, неизвестные камни, закрытую четвёртую ячейку, атомарность отказа, перестановку без дублей и повреждённую панель. Он проверяет модель, не заменяет будущую проверку игрового интерфейса.

## Проверка подготовки

- FadedNavEditor собран на UE 5.8.3 в отдельной рабочей копии. Открытый редактор основного проекта не закрывался, его исходники и ресурсы не изменялись.
- `FadedNav.Inventory.Assignment`: Result=Success.
- Отдельный режим `AFNInventoryPreviewGameMode` рисует фикстуру экрана с тестовыми предметами, не использует настоящего героя. Предпросмотр 1280×720 отрисован движком и просмотрен; иконки загружены из PNG временно, без импорта ресурсов в проект.
- Для повторения: открыть `/Engine/Maps/Entry?game=/Script/FadedNav.FNInventoryPreviewGameMode` с ключами `-game -InventoryPreview -RenderOffscreen -ResX=1280 -ResY=720 -ForceRes -InventoryIconDir="D:/Ai/Game/docs/art/skills/C1-Yav/01-grom/icons/perun_set_v2/final"`. Фикстура сохраняет `Saved/Screenshots/Inventory/preview.png` и завершает процесс. Для обычной игры этот режим не выбирается.
- Предпросмотр проверяет только отрисовку. Текущая фикстура показывает режим требы; настоящие нажатия I/Esc, замедление, откаты и проверки текущего расстояния до требы ещё не подключены.
