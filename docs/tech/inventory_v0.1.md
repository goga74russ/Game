# Инвентарь демо

2026-09-28. Подключён после работы Aura над Искрой.

## Управление

I открывает и закрывает сумку, Esc закрывает любое меню. Карта, древо и инвентарь не открываются одновременно. В сумке запрещены движение, бой, смена оружия и взаимодействие; мир замедлен как в остальных меню. Смерть закрывает меню и восстанавливает время.

Снаряжение и шесть ячеек калиты отображают реальные данные персонажа. Переодевание мышью пока не добавлено: доспех в прототипе хранится как суммарный бонус, оружие меняется Q.

## Камни

Пять найденных камней и три активных слота. Выбрать камень мышью, затем слот 1–3. Перенос установленного камня меняет слоты местами. Менять можно только в радиусе 350 см по горизонтали от действующей требы, как при отдыхе. В пути доступен просмотр.

Применение повторно проверяет актуальную дистанцию, владение и отсутствие дублей. Откаты хранятся по ID навыка, а не по слотам: перестановка их не сбрасывает. UI не хранит вторую копию предметов. Поддержки не подключены.

Иконки импортированы из собственного сгенерированного набора в /Game/UI/Inventory/T_*. HUD удерживает текстуры через UPROPERTY.

## Проверки

FNInventoryTests: отказ вне требы, установка, обмен, повторная установка, снятие, неверные слоты и повреждённые панели.

-InventoryTest запускает проверку реального персонажа на карте Vysi: открытие/закрытие, ограничение требы, откат, запрет стрельбы, взаимоисключение меню, смерть, активность SparkFX при смене стадии. Сохраняет кадры в Saved/Screenshots/Inventory.

Изолированный -InventoryPreview остаётся фикстурой для проверки макета.
