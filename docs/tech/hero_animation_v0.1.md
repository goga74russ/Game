# Анимации героя: изометрический прототип

2026-09-28. Рабочий набор для проверки боя, не окончательный облик героя.

## Что подключено

- Направленный бег вперёд, назад и в стороны: Wraith. Диагонали смешиваются с общей фазой шага; темп зависит от фактической скорости.
- Выстрел: Wraith, отдельный слой от первой кости позвоночника. Ноги продолжают движение. Работает у Скелета и Плоти.
- Ближний удар Плоти: оружейный замах Greystone, перенесённый на Wraith.
- Ближний удар Скелета: щитовой выпад Greystone без щита, временное движение для удара рукой. Это не финальный специально записанный кулачный удар.
- Уклонение Скелета: короткая часть выпада с пригнутым корпусом, рывок без кувырка.
- Уклонение Плоти: перекат из Game Animation Sample; используется участок 0,95–2,20 с, без падения с высоты и последующего бега.
- Искра сохраняет вспышку и телепорт: человеческие движения ей не добавлены.

## Код и тайминг

`UFNHeroAnimInstance` вычисляет позы в C++. Переходы к действиям и обратно смешиваются за короткое время. Оригинальный Blueprint Wraith для героя больше не используется. Модель Плоти пока остаётся Wraith; Скелет копирует её позу существующим преобразованием костей.

Источник перемещения — капсула персонажа. Перемещение исходных клипов извлекается из позы и не двигает героя второй раз. У щитового выпада также убирается горизонтальное смещение таза: этот клип хранит перемещение на тазе, поэтому одного извлечения root motion недостаточно. Перед оценкой на рабочем потоке данные копируются с игрового потока.

Ближний удар теперь проходит через замах: контакт через 0,12 с у Скелета и 0,17 с у Плоти [Д]. Цена, урон, радиус и длительность восстановления сохранены. Уклонение или смерть отменяют ещё не прошедший контакт. Направление удара фиксировано на время его восстановления. Выстрел не прерывает ближний удар.

## Восстановление локальных ресурсов

Публичный репозиторий содержит код и сценарий подготовки, но не производные лицензированных анимаций.

1. Установить Paragon Wraith и Greystone в проект из своей библиотеки Fab.
2. Установить Game Animation Sample. По умолчанию сценарий ищет `D:/Ai/UESamples/GameAnimationSample`; другой путь задаётся переменной `FN_ANIMATION_SAMPLE`.
3. Закрыть редактор и выполнить через `UnrealEditor-Cmd.exe` сценарий `tools/editor/retarget_hero_actions.py` с плагинами PythonScriptPlugin и IKRig.
4. Сценарий копирует только манекен и один исходный клип, создаёт IK Rig / IK Retargeter и четыре анимации в `/Game/Characters/HeroActions`. Папка `Characters` исключена из Git.
5. Собрать модуль проекта и запустить карту Высей.

Сценарий можно запускать повторно: его выходные анимации заменяются, исходные пакеты Paragon не изменяются. Исходные уведомления о частицах и звуках удаляются из копий; звуковой набор для этих действий ещё предстоит подключить.

## Проверка

Ключ `-AnimationTest` запускает в игре проверку контакта, отмены удара, поз уклонения обеих стадий, отсутствия смещения тела исходным root motion, выстрела, движения и блокировки действий картой. Скриншоты сохраняются в `Saved/Screenshots/Animations`. Дополнительно используется существующий `-IsometricTest` для проверки управления.

Окончательная оценка движения, переходов и удобства боя — при ручном прохождении. Этот набор не заменяет будущие авторские анимации и модель героя по лору.
