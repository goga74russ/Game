# Древо: содержание узлов (таблицы)

По файлу на сектор бога, порядок — кольцо GDD §3: `01-grom.csv` (Перун) … `08-zhar.csv` (Сварог). Формат под русский Excel (UTF-8 с BOM, «;»), как и таблицы навыков.

**Игра читает таблицу открытого сектора при запуске** (`Source/FadedNav/Private/FNSkillTree.cpp`): поменял цифру или название → перезапустил игру. В логе — строка `Tree: … from …`. Если таблицы нет или она неполная (нужны: 1 gate, ≥1 small, ≥1 notable, 2 keystone), игра берёт встроенные значения.

**Форма дерева** (ветви, кластеры, число узлов) — в коде; таблица задаёт **содержание**: малые узлы идут по ветви по кругу, значимые — по одному на кластер по порядку, ключевые — левый и правый на конце ветви.

| Колонка | Что |
|---|---|
| kind | gate / small / notable / keystone |
| order | порядок внутри вида |
| name_ru, desc | название и описание (как в подсказке) |
| stat1..3, value1..3 | до трёх эффектов узла |
| icon | иконка (1 молния, 2 глаз, 3 щит, 4 стопа, 5 капля, 6 кольцо, 7 кость, 8 веретено, 9 пламя, 10 череп, 11 солнце, 12 ветер) |
| sealed | 1 — под печатью (нужна руна-ключ) |
| rune_order | порядок выпадения руны-ключа (0 — первая) |
| notes, status | для людей |

**Эффекты (stat):** increased (складываются): `ranged` урон выстрелов, `reserve` запас патронов, `fire_rate` скорострельность, `weak` урон по слабым местам, `reload` перезарядка, `max_hp_flat` здоровье (число), `melee` урон удара, `melee_heal` лечение за удар (число), `stamina_regen` выносливость, `damage_taken` получаемый урон (минус = меньше), `dodge_cost` цена уклонения, `move` скорость, `max_hp_inc` здоровье (%), `iframes` неуязвимость при уклонении (с), `weak_flinch` (1 = выстрел в слабое место прерывает замах). More (перемножаются): `ranged_more`, `damage_taken_more`, `fire_rate_more` (1,3 = в 1,3 раза).

Дробные можно писать через запятую (0,05). Все числа — [Д] до плейтеста.
