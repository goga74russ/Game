# Секреты и квесты v0.1 (черновик systems-wilson, 2026-09-27)

Статус: предложение, решает директор. Лор-наполнение — летописец. [Д] — допущение, проверить плейтестом.

## 0. Вывод
- Одна система «Обряд» на три типа: **скрытая цепочка**, **обучающий квест**, **супер-квест**. Разница только в подаче (есть ли голос/журнал) и длине, движок один.
- Цепочка = граф из 5 кирпичей: **Предмет, Объект, Действие, Условие, Итог**.
- Главный рычаг глубины — **стадия героя как условие**: Искра, Скелет и Плоть по-разному взаимодействуют с одним объектом. Бесплатно по контенту: уровень уже есть, стадии уже есть.
- Награды — **горизонтальные**: облик, побочное свойство, ключ к месту, реплика/лор. Не вертикальная сила. Сверхредкое = престиж (GDD §6).
- Демо: 1 обучающий квест + 2 скрытые цепочки (+1 резерв). Шагов: скрытая ≤ 4, супер-квест ≤ 12 в 3–4 главах.

## 1. Модель

### 1.1 Типы
| Тип | Подача | Шаги | Журнал | Награда | Пропускаемость |
|---|---|---|---|---|---|
| Обучающий квест | NPC говорит, что нужно, но не как | 2–3 | запись «Обряд начат» | малая, гарантированная | нельзя проиграть, можно пропустить |
| Скрытая цепочка | ничего; только окружение | 2–4 | запись появляется **после** 1-го верного шага | облик / ключ / побочное свойство | пропуск — норма (цель: находит 20–40% игроков [Д]) |
| Супер-квест | несколько скрытых цепочек, связанных общим предметом-нитью | 8–12, через 3–4 биома/главы | страница-«узор», заполняется | престиж-вещь, место, реплика бога | не в демо |

### 1.2 Кирпичи
| Кирпич | Что это | Пример |
|---|---|---|
| **Предмет** | квестовый предмет в «Суме», не экипировка | Крынка молока |
| **Объект** | точка взаимодействия в мире с состояниями | Коза, конский череп на колу |
| **Действие** | глагол героя: взять, дать, полить, ударить, сжечь, выстрелить в, постоять рядом N с, прийти стадией X | «полить» |
| **Условие** | фильтр: стадия героя, гроза (вспышка в последние 5 с), зона-Dimness, убит ли моб X, время с шага N, есть ли предмет | стадия = Плоть |
| **Итог** | что меняется: выдать предмет, сменить состояние объекта, открыть проход, реплика, награда | череп → предмет «Конский шлем» |

Правило: **один шаг = Действие над Объектом (+Предмет) при Условии → Итог.** Не больше одного условия сверх стадии на шаг.

### 1.3 Сума (хранение)
- Отдельная от экипировки, **6 ячеек** [Д], без веса (в GDD веса нет).
- Квестовый предмет не выпадает при смерти (GDD: смерть в PvE не отнимает экипировку — распространяем на Суму). Добыча забега теряется, Сума — нет.
- Портящиеся предметы запрещены в демо (молоко не скисает): таймеры = фрустрация без выигрыша.
- Потерянный/выброшенный предмет возвращается к источнику (коза снова даёт молоко). Цепочку нельзя сломать навсегда.

### 1.4 Награды
| Вид | Сила | Пример | Правило |
|---|---|---|---|
| Облик | 0 | шлем-череп поверх брони | основной вид награды |
| Побочное свойство | горизонтальное, ≤ одного нотабла по ценности | +1 заряд блинка Искры / звон выдаёт невидимых | не лучше обычного выбора, а **другое** |
| Ключ | доступ | шорткат, тайник с Золой/рунами, реплика | тайник даёт обычный лут чуть раньше, не уникальную силу |
| Руна-трофей | престиж | руна с особой гравировкой, функция = обычной | вес 0 в расчёте силы |

Ценность в единицах силы: бюджет билда в демо ≈ 14 очков дерева. Награда цепочки ≤ **1 очко эквивалента** (≤7% бюджета). Если секрет даёт больше — его «обязаны» искать все, и он перестаёт быть секретом (становится гайдом).

## 2. Честность

### 2.1 Правило трёх знаков
Каждый неочевидный шаг подсказан **тремя независимыми каналами** до того, как игрок до него дойдёт; игрок должен уметь догадаться по любым двум:
1. **Окружение**: следы на объекте (у черепа — сухая белая корка, пустая крынка у кола, мокрое пятно на земле).
2. **Слово**: фраза NPC/деда, не адресованная игроку («Бабка поила череп, чтоб скотину берёг…»).
3. **Повтор**: тот же жест встречается раньше в безопасной форме (обучающий квест учит «полить» на требе/идоле).

### 2.2 Анти-«угадай мысль дизайнера»
- Глаголы — только из **малого словаря** (≤ 8 действий на всю игру: взять, дать, полить, зажечь, ударить, выстрелить, постоять, прийти стадией). Нет контекстного «использовать предмет на всём».
- Каждый объект с состоянием **реагирует** на неверное, но близкое действие (череп на выстрел звенит бубенцом, на удар — качается). Отклик = «ты на верном месте».
- Нет неверного пути, который ломает цепочку.
- Логика — из фольклора, а не из головы: летописец даёт обряд, который реально существовал или правдоподобен (кормление оберега).
- Ограничения по длине и расстоянию:

| | Скрытая | Супер-квест |
|---|---|---|
| Шагов | 2–4 | 8–12 |
| Шагов без отклика подряд | ≤ 1 | ≤ 2 |
| Расстояние между шагами | в одной зоне или соседней | разные главы; внутри главы — как скрытая |
| Условий на шаг сверх стадии | ≤ 1 | ≤ 1 |
| Обязательный «таймер» | нет | нет |

Вероятностная проверка [Д]: если шансы догадаться на шаге p, то цепочка из n шагов находится с вероятностью ≈ p^n. При p=0,6: n=2 → 36%, n=3 → 22%, n=4 → 13%. Отсюда потолок 4 для скрытой; супер-квест держится только потому, что каждая его часть — отдельная короткая цепочка с журналом.

## 3. Стадии героя как механика
| Стадия | Может | Не может | Уникальное для секретов |
|---|---|---|---|
| **Искра** | пролететь блинком через щели и решётки; зажечь (плазма); видеть «следы памяти» (тусклые отпечатки) | брать и нести предметы, говорить с живыми (они её не видят), доить | видит скрытые знаки; проходит туда, куда Плоть не пролезет |
| **Скелет** | взять **только кость/металл** (без плоти предметы выскальзывают — нет пальцев с кожей); стоять среди мёртвых — деды/навьи принимают за своего; ударить | нести жидкость (протекает), говорить с живыми (пугаются) | разговор с навьими/дедами; взять кость-ключ |
| **Плоть** | всё бытовое: доить, нести, лить, говорить с живыми | пройти щель; видеть следы памяти | бытовые обряды |

Следствие: стадии уходят (эволюция односторонняя в главе), значит часть секретов **упускается навсегда в этом прохождении** — это хорошо для повторных прохождений, но нужна страховка: в демо ни одна награда не требует стадии, которую уже нельзя вернуть в этом прохождении, **кроме одной цепочки** (намеренно «ты опоздал» — рассказ о росте).

## 4. Демо Высей: объём
Рекомендация: **1 обучающий + 2 скрытые, 1 резерв** (делать, если останется время).

| # | Тип | Зона | Стадия | Шаги | Награда |
|---|---|---|---|---|---|
| О1 | Обучающий «Напои требу» | 1–2 | Искра → Плоть | 2 | облик свечения требы + учит глагол «полить» |
| С1 | Скрытая «Конский шлем» | 4 | Плоть | 3 | облик-шлем + побочное свойство |
| С2 | Скрытая «Кость присяжника» | 2 | Скелет (упускаемая) | 2 | руна-трофей / реплика навьи |
| С3 (резерв) | Скрытая Искры «След в сухоречье» | 1 | Искра | 2 | тайник с руной-ключом чуть раньше |

Объём контента [Д]: 1 цепочка ≈ 2–4 объекта с состояниями + 1 предмет + 2–3 реплики. Итого демо: ~8 объектов, 4 предмета, ~8 реплик.

### Пример С1 «Конский шлем» на кирпичах
| Шаг | Действие | Объект | Предмет | Условие | Итог |
|---|---|---|---|---|---|
| 1 | взять (доить) | Коза в загоне | — | стадия = Плоть | в Суму: Крынка молока |
| 2 | полить | Конский череп с бубенцом на колу | Крынка молока | стадия = Плоть | череп: «напоен», бубенец звенит сам |
| 3 | постоять рядом 3 с | череп «напоен» | — | гроза (вспышка ≤ 5 с назад) | череп снимается → «Конский шлем» |

Знаки: белая корка и пустая крынка у кола; дед: «Коня поить надо, а то грозу не отведёт»; повтор — О1 учит «полить».
Награда: облик шлема на слот брони (не отдельный слот) + побочное свойство «Бубенец»: звенит, когда элита начинает телеграф вне поля зрения [предл.]. Сила ≈ 0 урона, польза — информация (читаемость, не цифры).

### Пример С2 «Кость присяжника» (упускаемая)
| Шаг | Действие | Объект | Условие | Итог |
|---|---|---|---|---|
| 1 | взять | Кость у Присяжного камня | стадия = Скелет (Плоть — «чужое, не тронь», Искра — не берёт) | в Суму: Кость |
| 2 | дать | навья-присяжник | стадия = Скелет | реплика-лор + руна-трофей |

## 5. Минимум кода (для техлида, без реализации)
Данные, не скрипты: цепочки собираются дизайнером в DataAsset.

| Сущность | Суть | Состояние |
|---|---|---|
| `UFNRiteDef` (DataAsset) | цепочка: тип, список шагов, награда | статичные данные |
| `FFNRiteStep` | {Verb, TargetObjectId, RequiredItem?, Conditions[], Outcome} | — |
| `EFNVerb` | enum ≤ 8 глаголов | — |
| `FFNCondition` | {Stage mask, bRecentThunder, DimnessRange, RequiresFlag} | — |
| `UFNInteractableComponent` | на объекте: Id, текущее состояние (name), какие глаголы принимает, отклик на «близкое» действие | `CurrentState` |
| `UFNSatchelComponent` | Сума на герое, 6 ячеек | список `ItemId` |
| `UFNRiteSubsystem` | принимает событие (Verb, Object, Hero), ищет подходящий шаг, применяет Outcome, пишет журнал | `Map<RiteId, StepIndex>`, флаги мира |
| Сохранение | прогресс обрядов, состояния объектов, Сума | в общий сейв |

Событие грозы: подсистема погоды шлёт `OnThunderFlash` (время) — уже нужно для звука «немого грома».

## 6. Риски и эксплойты
| Риск | Как проявится | Контрмера |
|---|---|---|
| Секрет сильнее обычного выбора | гайд за 1 день, «обязательный» | бюджет ≤ 1 очка дерева; горизонтальные свойства |
| Пиксель-хантинг | игроки жмут на всё | малый словарь глаголов, у объектов с состоянием — видимый отклик и форма |
| Сломанная цепочка | предмет выброшен/потерян | возврат к источнику, нет портящихся предметов |
| Упущенная стадия | фрустрация «опоздал» | только одна упускаемая цепочка в демо, её намёк заметен заранее |
| Фарм | коза даёт бесконечное молоко → продажа | предметы Сумы не разбираются в Золу; 1 награда на героя |
| Раздувание | каждая сцена хочет свой обряд | потолок: 3 цепочки в демо, общий движок, новые глаголы — только решением директора |
| Мультиплеер (позже) | кто получает награду | каждый за себя, состояние объекта — локальное на игрока; решить до коопа |
| Тестирование | цепочку никто не нашёл | телеметрия: % нашедших каждый шаг; цель 20–40% на скрытую, < 10% — добавить знак |
