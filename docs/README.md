# Документы проекта

**Для текущей работы начни со [страницы демо Перуна](demo/README.md).**

## Основа

- [Видение](vision.md) — идея и направление игры.
- [GDD](GDD_v1.md) — действующие правила.
- [План демо](slice_v1.md) — объём текущей разработки.
- [Обзор](overview.md) — что сейчас реализовано и что предстоит.

## Разделы

| Раздел | Что искать |
|---|---|
| [lore](lore/README.md) | Мир, боги, истории и реплики |
| [level](level/README.md) | Маршрут и размещение встреч |
| [systems](systems/README.md) | Механики и таблицы баланса |
| [quest](quest/README.md) | Квесты по мирам и биомам |
| [art](art/README.md) | Облики, палитры, карточки и промпты |
| [ui](ui/README.md) | Макеты интерфейса |
| [tech](tech/README.md) | Реализация, импорт, архитектура и лицензии |
| [reviews](reviews/README.md) | Проверки и замечания |
| [archive](archive/README.md) | История обсуждений и старые версии |

Название папки не делает документ утверждённым: статус нужно читать в его шапке. Архив не является источником новых правил. При расхождениях правил сверяйся с GDD и планом демо; решения директора — в [consensus](../memories/consensus.md).
