# Архив

Материалы сохраняются для истории решений. Они могут противоречить текущей реализации и друг другу. Правила разработки находятся в [GDD](../GDD_v1.md), объём демо — в [плане демо](../slice_v1.md).

- design/ — прежние обсуждения механик, экономики и боссов.
- history/ — старые журналы договорённостей.
- discussions/ — исходные диалоги по геймдизайну.

Новые механики описываются в systems/, уровни — в level/, проверки — в reviews/. Перенос в архив не отменяет ранее принятых директором решений: их действующее изложение нужно сверять с основными документами.
