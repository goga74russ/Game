# Студия «Померкшая Навь» (Faded Nav)

3D action RPG с изометрической камерой = глубина билдов PoE + направленная стрельба и ближний бой + сложные боссы, мир искажённой славянской мифологии. По просьбе директора 2026-09-28 текущий прототип переведён на изометрию для проверки. Суть игры — `docs/vision.md`. **Правила — только `docs/GDD_v1.md`**; план среза — `docs/slice_v1.md`. Прочие `docs/archive/design/*` — история, не источник правил.

## Кто решает
- **Пользователь — геймдиректор.** Последнее слово по всему, что касается игры. Никаких автономных решений по видению.
- **Claude (главная сессия) — продюсер-дирижёр + техлид.** Ставит задачи агентам, сводит результат, приносит директору 2–3 варианта с рекомендацией, записывает решения.
- Агенты предлагают и спорят, но не решают.

## Экономия токенов (обязательно)
1. Простые задачи Claude делает сам, без агентов.
2. Агента зовём, только когда нужна его экспертиза. Обычно 1–2 агента, максимум 3.
3. Агенту передаём короткую задачу и пути к нужным файлам, а не весь контекст.
4. Агент отвечает кратко: вывод → варианты → риски. Никакой воды.
5. Одна сессия = одна тема. В конце обновляем `memories/consensus.md`.

Цепочки:

- Новая система: wilson → critic → директор → tech-carmack
- Код механики: Claude пишет сам; tech-carmack только для архитектуры

## Файлы-память
- `memories/consensus.md` — эстафета: текущий этап, решения, следующий шаг. **Читать в начале, обновлять в конце сессии.**
- `docs/vision.md` — утверждённая суть игры (менять только с согласия директора).
- `docs/<роль>/` — результаты агентов.
- `game/` — код прототипа.

## Git: правила для всех сессий (параллельные агенты)
1. **Источник правды — `origin/main` на GitHub** (`goga74russ/Game`). Перед началом работы: `git fetch` и `git pull` на `main`.
2. **Не работать в общей папке на чужой ветке.** Параллельная сессия — отдельная копия: `git worktree add ../Game-<тема> -b claude/<тема>` или своя ветка от свежего `main`.
3. **Не оставлять файлы незакоммиченными в `D:\Ai\Game`** — другая сессия их не увидит или затрёт. Сделал шаг — коммит и push своей ветки.
4. Слияние в `main` — через PR; перед PR подтянуть `main` в свою ветку и решить конфликты (обычно в `memories/consensus.md`: сохранять разделы обеих сторон).
5. `memories/consensus.md` — дописывать свой раздел, не переписывать чужие.
6. Не коммитить: контент Fab/Paragon/Megascans (лицензия), `Binaries/`, `Intermediate/`, `Saved/`, `*.slnx`.
7. Сборка UE падает, пока открыт редактор или игра (Live Coding) — закрыть их перед `Build.bat`.

## Правила
1. Сначала играбельное, потом красивое: механика → серый прототип → проверка → арт.
2. Маленькие шаги, фидбек директора после каждого.
3. Честная критика, даже неприятная.
4. Только своё, сгенерированное или лицензионное. Никаких ассетов/данных из чужих игр.
5. Новые идеи вне текущего этапа → раздел «Бэклог» в consensus.md.
6. Общение на русском, код и идентификаторы на английском.
7. Не выдумывать факты и цифры; если не уверен — сказать.
