# Референсы

Общие исходные материалы, которые ещё не относятся к конкретной карточке арта.

**inbox/** — локальные входящие файлы, исключённые из Git. Перед публикацией нужно выяснить происхождение и права, дать понятное имя и выбрать тематическую папку. `1.png` перемещён сюда без изменения содержимого.

Референсы конкретного персонажа, навыка или места лучше хранить рядом с его карточкой в docs/art/. Рабочие ассеты UE находятся в game/FadedNav/Content/.
