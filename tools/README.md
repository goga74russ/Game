# Инструменты

- editor/ — Python-скрипты для Unreal: импорт, материалы, ретаргет, диагностика.
- heightmap/ — подготовка карты высот Высей.
- check_docs_links.py — проверка локальных ссылок Markdown; запуск: `python tools/check_docs_links.py`.

Перед запуском редакторского скрипта прочитай его заголовок: некоторые меняют ассеты и требуют закрытого UE. Импортированные файлы и кэш хранятся в проекте UE, а технические инструкции — в docs/tech/.
